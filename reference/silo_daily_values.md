# A List of SILO Daily Weather Values

A [vector](https://rdrr.io/r/base/vector.html) object containing 18
items representing valid values to supply to
[`get_patched_point()`](https://docs.ropensci.org/weatherOz/reference/get_patched_point.md)
and
[`get_data_drill()`](https://docs.ropensci.org/weatherOz/reference/get_data_drill.md)'s
`values` argument taken from the documentation for the SILO API.

## Usage

``` r
silo_daily_values
```

## Format

A [vector](https://rdrr.io/r/base/vector.html) object of 57 items.

## Source

<https://www.longpaddock.qld.gov.au/silo/about/climate-variables/>
