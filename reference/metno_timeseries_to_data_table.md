# Convert MET Weather API timeseries to data.table

Convert MET Weather API timeseries to data.table

## Usage

``` r
metno_timeseries_to_data_table(timeseries)
```

## Arguments

- timeseries:

  List of timeseries data from MET Weather API

## Value

A data.table with hourly forecast data
