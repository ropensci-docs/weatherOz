# A List of DPIRD Minute Weather Data Values

A [vector](https://rdrr.io/r/base/vector.html) object containing 12
items representing valid values to supply to
[`get_dpird_minute()`](https://docs.ropensci.org/weatherOz/reference/get_dpird_minute.md)'s
`values` argument taken from the documentation for the DPIRD Weather 2.0
API.

## Usage

``` r
dpird_minute_values
```

## Format

A [vector](https://rdrr.io/r/base/vector.html) object of 12 items.

## Source

<https://www.dpird.wa.gov.au/online-tools/apis/>
